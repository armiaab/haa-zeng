This code reproduces [Quantum Neural Network Inspired Hardware Adaptable Ansatz for Efficient Quantum Simulation of Chemical Systems](https://pubs.acs.org/doi/10.1021/acs.jctc.3c00527) by Zeng et al., with some modifications, using Qiskit instead of Q²Chemistry. It only works on POSIX systems because PySCF doesn't support Windows.

## Getting Started
```sh
python3 -m pip install -r requirements.txt
```
